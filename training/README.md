# Five Ball by Adam – אב-טיפוס

אפליקציית ווב (PWA) בעברית לפי מסמך האפיון של Five Ball: ספריית סרטונים בחמש קטגוריות (טכניקה אישית, מנטליות, תזונה, טיפים משחקנים, הכנה לשחקן), סדרות ורמות קושי, חיפוש, מועדפים, מעקב צפייה, המשך צפייה ואזור אישי.
פרויקט נפרד מלוח המשחקים שבשורש הריפו. אין שרת: הפרופיל וההתקדמות נשמרים במכשיר בלבד.

## הרצה מקומית
```
cd training
python -m http.server 8000
```
ואז http://localhost:8000

## עריכת תוכן (`data.json`)
- `categories` – חמש הקטגוריות. `planned` הוא יעד הסרטונים מהאפיון.
- `series` – סדרות בתוך טכניקה אישית.
- `videos` – סרטון: `title`, `cat`, `series`, `level` (0 מתחיל, 1 מתקדם, 2 מקצוען), `seconds`, ו-`desc` או `steps` + `equipment`.
- `video` – קישור יוטיוב, קובץ `videos/שם.mp4` או קישור https לקובץ וידאו. ריק = תמונת placeholder. בקובץ וידאו האפליקציה שומרת את מיקום הצפייה ומסמנת "נצפה" אוטומטית.

הכותרות והתיאורים הקיימים הם תוכן לדוגמה שנגזר מהאפיון ויש להחליף אותם בתוכן של המאמן.

## דף נחיתה
בכניסה ראשונה מוצג דף נחיתה (`#/about`): מה האפליקציה, מי המאמן, מידע להורים ושאלות נפוצות, עם כפתור כניסה להדגמה. צילומי המסך שבו נמצאים ב-`img/shots/`, ותמונת השיתוף ב-`img/og.jpg`.

## מסכי הדגמה
`#/signup`, `#/consent`, `#/plans`, `#/admin` מדגימים הרשמה, אישור הורים, מנויים וניהול תוכן. שום דבר לא נשלח לשרת. ב-`#/admin` עריכות (שם, רמה, קישור לסרטון) נשמרות במכשיר בלבד ואפשר לשלוח אותן בוואטסאפ כדי לעדכן את `data.json`.

`shoot.html` – דף צילום למאמן: אילו סרטונים לצלם קודם, איך לצלם, וסרטוני בדיקה לקפטן.

## מה לא קיים באב-טיפוס
הרשמה והתחברות אמיתיות, מערכת ניהול מלאה, מנויים ותשלומים. אלה דורשים שרת והם השלבים הבאים באפיון.
