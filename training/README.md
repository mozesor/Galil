# Five Ball by Adam – אב-טיפוס

אפליקציית ווב (PWA) בעברית לאימון כדורגל עצמאי: ספריית תרגילים, תוכניות אימון, טיימר לאימון, "האימון שלי" ומעקב רצף.
פרויקט נפרד מלוח המשחקים שבשורש הריפו. בלי שרת, בלי הרשמה – ההתקדמות נשמרת במכשיר בלבד.

## הרצה מקומית
```
cd training
python -m http.server 8000
```
ואז http://localhost:8000

## עריכת תוכן (`data.json`)
- `drills` – תרגיל: `title`, `cat`, `level` (0 מתחיל, 1 מתקדם, 2 מקצוען), `seconds`, `equipment`, `steps`.
- `video` – קישור יוטיוב, או קובץ `videos/שם.mp4`, או קישור https לקובץ וידאו. ריק = מוצג placeholder.
- `plans` – תוכנית: רשימת אימונים, כל אימון הוא רשימת מזהי תרגילים.

התרגילים הקיימים הם תוכן לדוגמה ויש להחליף אותם בתוכן של המאמן.

## אימון לקבוצה (מצב מאמן)
המאמן מסמן תרגילים בכוכב, נכנס ל"שליחת האימון לקבוצה" ומקבל קישור לשליחה בוואטסאפ.
האימון מקודד בתוך הקישור עצמו (`#/w/...`), בלי שרת. שחקן שפותח אותו מבצע את האימון ושולח למאמן הודעת סיום בוואטסאפ.
